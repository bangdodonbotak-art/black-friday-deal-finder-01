Deal Radar — a real Black Friday deal finder for make.fun's "Build the best real Black Friday deal finder" bounty ($250, top 20 share). 26 deals across 5 stores and 6 categories, every price found and checked by the agent on 27 Nov 2026 at the store named, each with product, store, sale price, usual price, discount, dollars saved, an honest verdict, evidence note, check time and source. Search + filters by category, store and discount that work, 4 sorts, deal of the day, and a phone layout. Static files only — no network at runtime.

## Run it

```sh
node main.ts
```

or serve `app/` locally and open `app/index.html`.
